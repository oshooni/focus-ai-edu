시작하기 전에

이 가이드는 포커스 AI EDU 수업과 함께 보는 자료예요. 수업에서 다루는 내용만 담았으니, 부담 없이 필요한 부분만 펼쳐 보세요.

이 가이드는 이렇게 써요

  • 수업 전 — 03 요금제와 04 설치 & 로그인까지는 첫 수업 전에 꼭 끝내 주세요. 이게 준비돼 있어야 수업 시간을 설치가 아니라 '만들기'에 쓸 수 있어요.
  • 수업 중·후 — 05~07은 손이 기억할 때까지 옆에 두고 펼쳐 보는 용도예요. 막히면 여기서 다시 찾아보면 됩니다.
왕초보 안심 포인트 클로드 코드는 코딩을 배우는 도구가 아니에요. "이거 해줘"라고 말로 시키면 컴퓨터 안에서 대신 일해주는 AI예요. 까만 터미널 화면이 무섭다면 데스크톱 앱으로 시작할 수 있으니 걱정 마세요.
01

클로드 코드란?

한 줄로 말하면, 내 컴퓨터 폴더에 직접 들어와서 파일을 읽고, 정리하고, 결과물까지 만들어 주는 AI예요.

우리가 평소 쓰는 claude.ai 웹은 대화창 안에서 답을 보여줘요. 파일도 하나씩 올려야 하고, 결과물은 복사해서 옮겨야 하죠. 클로드 코드는 다릅니다. 내 폴더 안으로 직접 들어와서, 수십 개 파일을 한 번에 읽고, 결과물을 파일로 만들어 둡니다.

claude.ai 웹클로드 코드
파일하나씩 직접 올림폴더째로 알아서 읽음
결과물복사해서 옮기기파일로 자동 저장
반복 작업매번 수동한 번 말하면 알아서
기억그 대화 안에서만내 규칙을 파일로 기억(07)
비유 하나. claude.ai가 물어보면 답해주는 대화 상대라면, 클로드 코드는 내 컴퓨터에 출근해서 같이 일하는 동료예요.
02

뭘 만들 수 있나요?

이름은 'Code'지만 코딩 전용 도구가 아니에요. 컴퓨터로 하는 거의 모든 일을 말로 시킬 수 있어요. 우리 수업의 핵심은 '내가 진짜로 쓸 한 가지'를 찾아 완성하는 거예요.

수강생들이 실제로 만드는 것들

  • 콘텐츠·SNS — 카드뉴스 자동 만들기, 블로그·뉴스레터 초안, 인스타 캡션 정리
  • 문서·업무 — 회의록 30개를 읽고 결정사항만 뽑아 한 파일로, 보고서 검토
  • 자료 정리·분석 — PDF·엑셀 한 번에 요약, 설문 결과 분석 (파이썬 몰라도 OK)
  • 나만의 작은 도구 — 자료 정리 웹페이지, 반복 작업 자동화기
막막해도 정상이에요. 처음엔 "이걸로 뭘 하지?"가 당연합니다. 첫 수업에서 내 일상·업무에서 반복되거나 귀찮은 일을 같이 끄집어내고, 강의 기간 안에 끝낼 수 있는 크기로 함께 다듬을 거예요. 빈 종이부터 시작하지 않으니 안심하세요.
03

요금제 — 유료 플랜이 필요해요

클로드 코드는 무료 플랜으로는 쓸 수 없어요. 수업 전에 유료 플랜 하나를 준비해 주세요.

꼭 확인 무료 클로드 계정으로는 클로드 코드가 실행되지 않습니다. 아래 둘 중 하나의 유료 구독이 있어야 해요. 첫 수업 전까지 결제까지 마쳐 주세요.
플랜월 요금이런 분께
Pro약 $20"클로드 코드가 뭔지 가볍게 써보고 싶다" — 체험용
Max약 $100~"수업 따라 제대로 만들어보고 싶다" — 사용량 한도가 넉넉

가볍게 시작한다면 Pro로 충분해요. 다만 Pro는 사용량 한도가 빨리 차서, 집중해서 만들다 보면 중간에 멈출 수 있어요. 수업과 숙제를 여유 있게 따라가고 싶다면 Max를 추천합니다. 최신 가격은 claude.com/pricing에서 확인하세요.

세션 사용량이 궁금하면 클로드 코드 안에서 /cost를 입력하면 지금까지 쓴 양을 볼 수 있어요.
04

설치 & 로그인

⭐ 첫 수업 전에 꼭 끝내야 하는 숙제예요. 두 가지 길이 있는데, 터미널이 부담되면 첫 번째를 고르세요.

길 A. 데스크톱 앱 — 터미널이 무섭다면 (입문자 추천)

까만 터미널 화면 없이, 익숙한 앱 창에서 클로드 코드를 쓸 수 있어요. claude.ai/download에서 데스크톱 앱을 설치하고 로그인한 뒤, 앱 안의 Code 탭에서 시작하면 됩니다. 진입장벽의 절반인 '터미널 공포'가 사라져요.

추천 처음이라면 길 A(데스크톱 앱)로 시작하는 걸 권해요. 익숙해진 뒤에 길 B로 넘어가도 전혀 늦지 않습니다.

길 B. 터미널 설치 — 명령어 한 줄

아래 명령어를 그대로 복사해서 붙여넣고(Cmd+V / Ctrl+V) Enter만 누르면 돼요. 뜻을 이해할 필요 없어요. 설치엔 Node.js 같은 사전 준비가 필요 없습니다.

터미널 열기: Cmd+Space → "terminal" 검색 → Enter

# 방법 1 — 기본 설치
$ curl -fsSL https://claude.ai/install.sh | bash

# 방법 2 — Homebrew를 쓴다면
$ brew install --cask claude-code

PowerShell 열기: Win+R → "powershell" 입력 → Enter

# 방법 1 — PowerShell에서 바로 설치
> irm https://claude.ai/install.ps1 | iex

# 방법 2 — WinGet을 쓴다면
> winget install Anthropic.ClaudeCode

설치 확인 & 로그인

$ claude --version   # 버전 번호가 뜨면 설치 성공
$ claude             # 실행 → 브라우저가 자동으로 열려요

claude를 처음 실행하면 브라우저에 로그인 화면이 떠요. 03에서 준비한 유료 계정으로 로그인하면 자동으로 인증이 끝나고 터미널로 돌아옵니다. 끝!

잘 안 될 때. 설치했는데 claude: command not found가 뜨면, 터미널을 완전히 닫았다가 다시 열어 보세요. 그래도 안 되면 claude doctor로 상태를 점검할 수 있어요. 수업 전에 막히면 슬랙 채널에 편하게 올려 주세요.
05

첫 사용법

설치가 끝났다면, 작업할 폴더에서 claude를 켜고 말로 시키면 됩니다. 잘 시키는 작은 요령 세 가지만 기억하세요.

요령 1. 구체적으로 말하기

모호하게 말하면 모호한 결과가, 구체적으로 말하면 좋은 결과가 나와요.

✕ 모호한 예

"문서 정리해줘"

✓ 구체적인 예

"이 폴더 회의록들을 날짜순으로 정리하고, 이번 달 결정사항만 뽑아서 요약.md로 저장해줘"

요령 2. 한 번에 하나씩

여러 개를 한꺼번에 시키면 중간에 길을 잃어요. 하나 끝나면 다음을 시키세요.

# 추천
> 먼저 카드뉴스 1번 글만 써줘
  (완성 확인 후)
> 좋아, 이제 2번 글 써줘

요령 3. @로 파일 콕 집어주기

"이 파일 읽고…"라고 설명할 필요 없이, @ 뒤에 파일 이름을 붙이면 그 파일을 바로 넘겨줘요. 한글 파일명도 괜찮아요.

> @회의록.txt 에서 할 일만 담당자별로 뽑아줘
> @설문결과.csv 분석해서 인사이트 3개 알려줘
> @docs/ 이 폴더 문서 전부 읽고 목차 만들어줘
마음에 안 들면 바로 말하세요. "좋은데 말투를 더 친근하게", "이 부분은 빼줘"처럼 피드백을 주고받으며 다듬는 게 정상적인 사용법이에요. 한 번에 완벽하지 않아도 됩니다.
06

터미널 기초 — 딱 다섯 개만

길 B(터미널)로 쓴다면 이것만 알면 길 잃을 일 없어요. 폴더를 '방'이라고 생각하면 쉬워요.

핵심 3단계: 방 만들고 → 들어가서 → 클로드 부르기

프로젝트마다 폴더(방)를 따로 만들고, 그 안에서 클로드를 켜면 작업물이 안 섞여요.

$ mkdir 끼리끼리   # '끼리끼리'라는 방(폴더)을 새로 만들고
$ cd 끼리끼리     # 그 방 안으로 걸어 들어가서
$ claude         # 그 방에서 클로드를 부른다

다른 작업을 하고 싶으면 cd ..로 방에서 나온 뒤, 새 방을 만들어 똑같이 하면 돼요.

길 잃었을 때: 나머지 2개

명령어뜻물어보는 것
pwdprint working directory"나 지금 어느 방에 있어?"
lslist"이 방 안에 뭐가 있어?"

이 둘은 클로드가 아니라 터미널한테 직접 묻는 거라서 토큰도 안 들어요. 헷갈릴 때마다 마음껏 쳐도 됩니다.

자주 하는 실수 ① 폴더 이름에 띄어쓰기 금지. 터미널은 띄어쓰기를 "단어가 끝났다"는 신호로 읽어요. mkdir research bot이라고 하면 폴더가 두 개 만들어져요. 대신 하이픈이나 언더바를 쓰세요 → mkdir research-bot
자주 하는 실수 ② 폴더가 바탕화면에 안 보여요! 터미널을 켜면 항상 '홈 폴더(~)'에서 시작해요. 바탕화면은 홈 폴더 안의 다른 방이에요. 바탕화면에 만들고 싶다면 먼저 이동하세요 → cd ~/Desktop
07

CLAUDE.md — 내 규칙을 기억시키기

선택 사항이에요. 클로드 코드는 세션이 끝나면 대화를 잊어버리는데, 이 파일 하나로 매번 설명하는 수고를 없앨 수 있어요.

CLAUDE.md는 클로드에게 주는 '지시서'예요. 폴더 안에 이 파일을 두면, 클로드 코드를 켤 때마다 자동으로 읽어서 내 규칙을 기억한 채로 일을 시작해요.

가장 쉬운 방법은 클로드한테 직접 만들어 달라고 하는 거예요.

> 이 폴더는 내 인스타 콘텐츠 작업방이야.
> 말투는 친근하게, 과장 표현은 쓰지 말고, 항상 한국어로 써줘.
> 이 내용으로 CLAUDE.md 파일을 만들어줘.

한 번 써두면 다음 세션부터는 "친근하게 써줘"를 매번 말하지 않아도 알아서 지켜요. 콘텐츠 작업이라면 이런 걸 적어두면 좋아요.

  • 이 폴더가 하는 일 — "인스타 카드뉴스와 캡션 작업방"
  • 말투·스타일 — "친근하지만 과장 금지, 항상 한국어"
  • 하지 말 것 — "경쟁사 실명 언급 금지" 같은 금지 사항
  • 저장 규칙 — "초안은 drafts/ 폴더에, 파일명은 날짜_주제.md"
이게 마지막이에요. 여기까지 손에 익으면 수업을 따라오는 데 필요한 클로드 코드 기초는 끝입니다. 나머지는 수업에서 직접 만들어 보면서 자연스럽게 익히게 될 거예요.
